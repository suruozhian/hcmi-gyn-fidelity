hcmi-gyn-fidelity v1.0.0 — analysis code for 'Patient-deduplicated lineage and molecular class annotations for 215 ovarian
and endometrial cancer models' (Scientific Data Data Descriptor; data records on figshare)

Contents: analysis scripts (Python 3.13), environment.yml, configuration files, download manifests with md5 checksums
(data_manifest.csv, inputs/manifests/), small shipped inputs (inputs/), regression tests and expected values (tests/).
No raw data are included; all inputs are public and are downloaded by fetch_public_data.py (eight files from the DepMap portal
must be downloaded manually for the full re-run, three of them for Table 2 alone; see README_pipeline.md).

Claude Opus 5.5 (Anthropic) was used to assist with code writing and data analysis under the authors' supervision (Data Descriptor, Methods, 'Use of artificial intelligence tools'). All code and outputs were reviewed and verified by the authors with the tests in tests/ (including the gene-alignment regression test) and the clean-room re-run described in README_pipeline.md. No figure was generated by AI; all figures are produced by this code (matplotlib) from public data.

Quick start (details, runtimes and disk requirements in README_pipeline.md):
  conda env create -f environment.yml
  bash reproduce_table2.sh                      # Table 2 from public downloads, compared cell by cell
  bash reproduce_all.sh <published_package>     # every analysis; <published_package> = folder holding the
                                                # submitted manuscript.md, tables/, figures/ and supp/ files,
                                                # used for the final comparison (default ../..)
