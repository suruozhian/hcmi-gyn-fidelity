## Curation rules of hand-curated inputs
- `sample_annotations.csv`: one row per profile, from the resource's own metadata. HCMI: model/tumour role, case, lineage
  and histology from the GDC case and sample records (histology from the GDC primary diagnosis; step `endometrial` checks it
  against the GDC diagnoses extract); the three uterine leiomyosarcoma stems (HCM-BROD-0351, -0649, -0871; Methods 2.1)
  are not annotated. DepMap 2D lines: DepMap Model.csv (OncotreeLineage Ovary/Fallopian Tube or Uterus;
  non-carcinoma subtypes excluded: choriocarcinoma, uterine leiomyosarcoma, uterine sarcoma/mesenchymal, endometrial stromal
  sarcoma, mixed germ cell, granulosa cell, immortalised ovarian cells, small cell carcinoma of the ovary, malignant Brenner
  tumour, ovarian cancer other); histology mapped from OncotreeSubtype; patient = PatientID. NextGen: histology from
  OncotreeCode (LGSOC, HGSOC, MOV, UCS, UEC, USC, UMEC mapped to the corresponding classes). Sanger organoids: ovarian
  organoids of the clinical table of Supplementary Table 2 (histology from the TCGA code; patient = individual ID).
  GSE307568: patient-derived organoid libraries of tumours (normal tissue excluded), histology and grade from the authors'
  Supplementary Table 1. E-MTAB-10664: histology from the SDRF disease field (mixed if several), patient from the sample name
  (OEC-NN). GSE208216: tumour PDOs only (fallopian-tube organoids excluded), high-grade serous ovarian.
- `inputs/units_215.csv`: one independent unit per patient and resource-independent key: DepMap lines sharing a PatientID
  form one unit; Sanger organoids of one individual form one unit; the five official NextGen-HCMI pairs and ACH-002419 count
  under HCMI; E-MTAB-10664 OPDX-O-10 is the same patient as OEC-10; GSE208216 PDOs are merged with another organoid only if
  their residual expression correlation is >= 0.70 (none). When a key has several units the resource priority is HCMI >
  Sanger > NextGen > GSE208216 > DepMap 2D > GSE307568 > E-MTAB-10664; within a resource, the first model unit in
  alphabetical order is kept (for DepMap sibling lines, the representative chosen in the earlier exploratory deduplication).
  The DNA-only NextGen model ACH-003239 is not an expression unit. Applying these rules to `sample_annotations.csv` gives
  exactly the 215 shipped units.
- Identifier crosswalk: HCMI case, DepMap ModelID and Sanger model ID linked through the HCMIID and SangerModelID columns
  of DepMap 26Q3 Model.csv and the Cell Line Name of NextGen Supplementary Table 1 (141 gynaecological rows; the script
  stops unless the 141-row 26Q3-merged version is used).
- `GSE121103_rna_colmap.csv`: the 19 RNA-Seq samples of the GEO series matrix (library strategy RNA-Seq): title, GSM
  accession and tissue characteristic; count-file column = the "processed data column header" given in the sample
  description (all 19 present in the count file); histotype from the title (CCOC, EnOC, HGSOC, MOC mapped to CCC, EC,
  HGSC, MC).

## Gene key (round 4, 2026-10-08): Entrez Gene ID (primary); gene symbol (sensitivity)
All matrices are keyed by NCBI Entrez Gene ID, mapped with the HGNC complete set (`hgnc_complete_set.txt`; source URL,
file date, download date and md5 in `inputs/annotation/hgnc_provenance.json`). Rules (`genemap.py`):
- E1: Ensembl gene ID -> Entrez ID of the HGNC record carrying that Ensembl ID; Ensembl IDs carried by HGNC records with
  different Entrez IDs (one-to-many) are excluded.
- E2: Ensembl ID absent from HGNC -> GENCODE v36 gene name, only if it equals a unique HGNC approved symbol whose Entrez
  ID is not already assigned by E1. Otherwise excluded (E3). GENCODE v36 protein-coding: E1 19,367; E2 30; excluded 547.
- Symbols (Sanger organoids, E-MTAB-10664): S1 approved symbol; S2 previous symbol that is unique in HGNC; aliases not
  used; otherwise excluded.
- DepMap / NextGen: Entrez ID from the `SYMBOL (Entrez)` column header.
- Many-to-one (several source genes -> one Entrez ID, e.g. duplicated Entrez IDs in the DepMap 24Q4 header): per-sample max.
Mapping statistics and a QC against the symbol-keyed matrix: `reference/gene_map_summary.json`.
`--gene-id symbol` reproduces the earlier symbol-keyed analysis (sensitivity analysis; tag suffix `_symbol`).

## Gene alignment and regression test
`fidelity_core.py` holds Method A, Method B (Celligner-like) and the helpers `aligned()` / `assert_same_order()`: before
every matrix operation both operands are reindexed to an explicit gene list and their gene order is asserted (Method A,
Method B centring/covariance/projection, histotype centroids, identity check). The earlier Method B code
(`Eb.dropna(how='all').sub(mu_cl)`) re-sorted genes alphabetically whenever a feature gene was absent from the DepMap
file, misaligning the DepMap and tumour covariances (DepMap 26Q3 with symbol keys: 36 absent feature genes). It is kept
only as `method_b_fit(..., legacy_bug=True)` for the regression test. The contrastive PCA is now estimated on feature
genes present in the DepMap file (loadings of absent genes = 0): zero-filled absent genes have zero model covariance, and
their uncancelled tumour covariance could otherwise dominate the components.
