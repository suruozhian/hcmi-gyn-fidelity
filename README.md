# hcmi-gyn-fidelity v1.0.0

Analysis code for the data records **"Patient-deduplicated lineage and molecular class annotations for 215 ovarian and endometrial cancer models"** (figshare, https://doi.org/10.6084/m9.figshare.PLACEHOLDER), described in a *Scientific Data* Data Descriptor of the same title.

Authors: Yu-Hua Ou, Bi-Jun Du, Qin Li, Li-Zhen Ye, Wen-Jing Shi — Department of Gynecology, The Second Affiliated Hospital of Guangzhou Medical University, Guangzhou, China. Contact: 1053668734@qq.com; swj3647@163.com.
Licence: MIT (see `LICENSE`). Citation: see `CITATION.cff`.

## What the code does

From public downloads (GDC Data Release 46.0, DepMap Public 26Q3 and 24Q4, the DepMap NextGen file set, the Sanger organoid figshare item, GEO/ArrayExpress series and HGNC), the pipeline rebuilds:

- patient-level deduplication into 215 independent expression units and the identifier crosswalk;
- TCGA nearest-centroid lineage calls (Method A, primary; Method B, Celligner-like) under strict and loose rules;
- the NextGen–HCMI multi-omic identity check;
- sensitivity analyses (equal depth, reference composition, DepMap release, gene key) and the gene-removal stability test;
- endometrial DNA-derived surrogate classes, their CPTAC UCEC evaluation, and HCMI paired tumour–model concordance;
- all main and supplementary figures and the data-record workbooks.

No raw data are included. All inputs are public and are fetched by `fetch_public_data.py` (download URLs and md5 checksums in `data_manifest.csv` and `inputs/manifests/`); eight files from the DepMap portal must be downloaded manually in a browser.

## Quick start

```bash
conda env create -f environment.yml      # Python 3.13; pinned versions
conda activate gyn-model-fidelity
cp config_paths.example.json config_paths.json   # edit paths, or use config_paths.cleanroom.json as is
bash reproduce_table2.sh                 # Table 2 from public downloads, compared cell by cell
bash reproduce_all.sh <published_package> # every analysis (about 22 GB of GDC downloads); see README_pipeline.md
python3 tests/test_gene_alignment.py --synthetic   # gene-alignment regression test (no input data)
```

Runtimes, disk requirements, step list and the clean-room re-run record are in `README_pipeline.md`; a short overview is in `README_Supplementary_Code.txt`.
